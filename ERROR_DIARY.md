# Дневник ошибок

## 2026-11-17 — Мок не проверяет SQL в PostgreSQL

Поддельный курсор проверяет только Python-вызов: какие аргументы переданы в `execute`, как обрабатывается `rowcount`, закрывается ли курсор. Он не отправляет SQL в базу и не выявляет ошибки в синтаксисе запроса, названиях таблиц или ограничениях схемы.

Для проверки SQL нужен настоящий PostgreSQL. Для `delete_product` проверять:

- `delete_product(conn, 999)` возвращает `0` и не вызывает ошибку;
- временный товар, созданный в базе, удаляется с результатом `1`;
- `get_product_by_id(conn, product_id)` после удаления возвращает `None`.

Мок использовать только как дополнительную проверку передачи параметров и обработки результата, а не как замену интеграционному тесту с базой.
